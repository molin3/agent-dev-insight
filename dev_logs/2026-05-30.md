### 脚本调试（反复修复了 4 轮）
问题：用户从 GitHub 下载 ZIP 后，setup.bat 闪退、start.bat 找不到 venv

根因分析：
1. `%~dp0..` 路径拼接在某些场景下不可靠
2. `pushd/popd` + `call activate.bat` 可能重置工作目录
3. `where python` 在某些系统上行为不稳定
4. GitHub ZIP 解压后有双层嵌套目录

最终修复方案（第 4 版）：
- 移除所有不稳定命令（where/python3/pushd/popd/EnableDelayedExpansion）
- pip 安装改为 `"%BACKEND%\venv\Scripts\python.exe" -m pip install`（不用 activate.bat）
- npm 安装改为 `npm install --prefix "%FRONTEND%"`（不用 cd）
- 所有错误分支统一 goto :end → pause，绝不闪退
- 开头打印完整路径便于调试
