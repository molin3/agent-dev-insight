# AgentDevInsight 浏览器交互测试指南

> 打开浏览器，跟着一步步操作。每个步骤都有「操作」和「预期结果」。

---

## 准备工作

1. 确认后端在运行：浏览器打开 http://localhost:8000/docs 看是否出现 Swagger 页面
2. 浏览器打开 http://localhost:3001

---

## 第一站：Dashboard 首页

**操作**：打开 http://localhost:3001

**你会看到的画面**：

页面顶部是深蓝色侧边栏（AgentDevInsight 标志），右侧主区域有 4 张卡片：

```
┌──────────────┐ ┌──────────────┐ ┌──────────────┐ ┌──────────────┐
│ Total Traces │ │ Avg Latency  │ │ Total Tokens │ │ Total Cost   │
│     4        │ │   10.9s      │ │    4150      │ │   $0.001     │
│ 4 completed  │ │              │ │              │ │ 0% error rate│
└──────────────┘ └──────────────┘ └──────────────┘ └──────────────┘
```

下方还有两个面板：Completion Stats 和 Alerts。

**检查清单**：
- [ ] 4 张卡片都有数字（不是空白）
- [ ] 左侧导航栏有 5 个菜单项：Dashboard / Traces / Datasets / Experiments / Evaluations
- [ ] 点击不同菜单，右侧内容会切换

**操作**：

**检查清单**：

## 第三站：Trace 详情页（核心功能）

**操作**：
1. 在 Traces 表格中，点击某个蓝色可点击的 trace 名称（比如 "全链路自动化测试"）
2. 页面跳转到 `/traces/一大串uuid`

**你会看到的画面**：

```
┌─────────────────────────────────────────────────┐
│ 全链路自动化测试          [completed]            │
├──────────┬──────────┬──────────┬────────────────┤
│ Latency  │  Tokens  │   Cost   │    Spans       │
│  6.4s    │    86    │ $0.00002 │      5         │
└──────────┴──────────┴──────────┴────────────────┘

┌──────────────────────────────────────────────────┐
│ [Waterfall]  [Replay]  [JSON]                    │
├──────────────────────────────────────────────────┤
│                                                  │
│  任务分析与规划  ████████░░░░░░░░░░░░░░░░░░░░░░░  │
│    搜索知识库    ░░░░████████████████████████████  │
│    查询用户数据  ░░░░░░░░░░░░░███████████████████  │
│    生成分析报告  ░░░░░░░░░░░░░░░░░░░░░░░░░░░░████  │
│    格式化输出    ░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░  │
│                                                  │
│  ■ agent  ■ llm  ■ tool  ■ span                 │
└──────────────────────────────────────────────────┘
```

**操作**：
3. 点击其中一条彩色横条（比如绿色的 tool 横条）
4. 右侧会弹出一个面板

**预期结果**：右侧面板出现 Span 详情，上面有 4 个标签：**INFO / INPUT / OUTPUT / JSON**

**操作**：
5. 点 **INFO** 标签 → 看到 Type、Status、Model、Latency 等信息
6. 点 **OUTPUT** 标签 → 看到工具返回的具体数据（JSON 格式）
7. 点 **JSON** 标签 → 看到这个 Span 的完整数据（可折叠的树形）

**操作**：
8. 点回上方的 **[Replay]** 按钮，切换到对话回放模式

**预期结果**：出现步骤卡片，每张卡片显示一个执行步骤。有 Prev / Next / All 按钮可以翻页。

**操作**：
9. 点 **Next** 按钮几次

**预期结果**：每次点击多展示一张步骤卡片，卡片有彩色背景区分类型。

**操作**：
10. 点回上方的 **[JSON]** 按钮

**预期结果**：显示整条 Trace 的完整 JSON 数据，可折叠展开。

**检查清单**：
- [ ] Waterfall 横条至少 3 条，颜色不同
- [ ] 点击横条 → 右侧弹出详情面板
- [ ] 详情面板 4 个标签都能点击切换
- [ ] Replay 模式有步骤卡片，可翻页
- [ ] JSON 模式可折叠展开
- [ ] 页面顶部有评分标签（绿色/黄色，如 completion_rate: 0.95）

## 第四站：Datasets 数据集管理

**操作**：
1. 点击左侧导航栏的 **"Datasets"**

**你会看到的画面**：页面标题 "Datasets"，右上角有个 **"+ New Dataset"** 按钮。

**操作**：
2. 点击 **"+ New Dataset"**
3. 弹出一个输入框区域，输入：
   - Dataset name：`我的测试数据集`
   - Description：`用于回归测试`
4. 点击 **Create** 按钮

**预期结果**：弹窗消失，表格出现一行新数据：

```
┌──────────────────┬─────────┬──────────────┬─────────┐
│ Name             │ Version │ Created      │ Actions │
├──────────────────┼─────────┼──────────────┼─────────┤
│ 我的测试数据集    │  v1     │ 2026-05-24   │  🗑     │
└──────────────────┴─────────┴──────────────┴─────────┘
```

**操作**：
5. 点击右侧的 **垃圾桶图标** → 删除这个数据集

**预期结果**：表格那一行消失。

**检查清单**：
- [ ] 可以创建数据集（表格新增一行）
- [ ] 可以删除数据集（行消失）

## 第五站：Experiments 实验管理

**操作**：
1. 点击左侧导航栏的 **"Experiments"**

**你会看到的画面**：页面标题 "Experiments"，右上角 **"+ New Experiment"** 按钮。

**操作**：
2. 点击 **"+ New Experiment"**
3. 填写表单：
   - Experiment name：`模型对比测试`
   - Task description：`比较 DeepSeek 和 GPT-4o 在文本摘要任务上的表现`
   - Description：`测试不同模型的效果`
4. 点击 **Create**

**预期结果**：弹窗消失，页面出现一张卡片：

```
┌──────────────────────────────────────────────────┐
│ 🧪  模型对比测试                    [pending]  🗑 │
│     比较 DeepSeek 和 GPT-4o 在文本摘要任务上...   │
└──────────────────────────────────────────────────┘
```

**操作**：
5. 点击 **垃圾桶图标** → 删除

**检查清单**：
- [ ] 可以创建实验（卡片出现在列表）
- [ ] 状态显示为 "pending"
- [ ] 可以删除实验

## 如果某个步骤没通过

| 现象 | 可能原因 | 解决 |
|------|----------|------|
| Dashboard 一直 Loading | 后端没启动 | 终端执行 `uvicorn app.main:app --port 8000` |
| Dashboard 一直 Loading（后端已启动） | CORS 端口不对 | 确认前端端口是 3001，后端已重启 |
| Traces 表格为空 | 没有数据 | 终端执行 `python scripts/test_flow.py` |
| Waterfall 是空的 | Trace 没有 Span | 重新跑 test_flow.py 生成数据 |
| Evaluations 显示 "No evaluations" | 没运行评估 | 进 Traces 详情页，或者跑 test_flow.py |
| 创建 Dataset 失败 | 后端挂了 | 检查后端终端有没有报错 |
